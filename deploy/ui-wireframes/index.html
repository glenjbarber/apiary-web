APIARY

Web UI wireframes

Eight directions for the Apiary web UI. Each opens on Colony health and uses the same sample Colony (skyview: 4 combs, 23 cells, 3 warnings, 1 join request) so they compare fairly.

01

Ledger

Grouped sidebar matching today's Resources, Topology, Colony, Combs sections. Stat strip, attention list, comb table.

 02

Palette

Top tabs, no sidebar. Comb cards with their cells. Press / for a command palette that holds every action.

 03

Honeycomb

The Colony as a hex map: each comb ringed by its cells. Click a comb for details and actions in a side panel.

 04

Inbox

Health as a triage list. What needs you sits on top, healthy subsystems below, detail and fixes on the right.

 05

Console

Monospace operator view. Status bar, keyboard shortcuts, dense tables, a : command line at the bottom.

 06

Tasks

Plain-language headline, then the common actions as labeled tiles. Health checklist and activity below.

 07

Matrix

Icon rail, tabbed overview. A comb by check health matrix using all seven status states.

 08

Blend

Sidebar and top bar from 7, layout from 1, status line from 5. Comb section switches between Table, Cards, and Matrix.

Left and right arrow keys flip between designs. Static mockups; links go nowhere.
